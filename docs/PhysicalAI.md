## 1. フィジカルAIとは

フィジカルAI（Physical AI）とは、**人工知能を現実世界のハードウェアやデバイスに応用**し、物理世界を認識・推論・行動する次世代のAI技術体系です。

### 1.1 シンプルな理解

| 比較 | 生成系AI（ChatGPT） | フィジカルAI（Physical AI） |
|------|-------------------|---------------------------|
| 役割 | **考える** | **考える + 行動する** |
| 対象 | テキスト・画像・データ | 現実世界のハードウェア |
| 例 | 文章生成、画像生成 | 自動運転、ロボット、ドローン |

> **生成式AI（ChatGPT）= 会思考**
>
> **フィジカルAI（Physical AI）= 会思考 + 会行动**

### 1.2 市場規模

- **2040年のAIロボット市場：60兆円**
- **2050年のフィジカルAI市場：50兆ドル**
- 過去18ヶ月間で**100億ドル超**がフィジカルAI分野に流入
- 2026年Q1のグローバル物理AIスタートアップ資金調達：**64億ドル超**

### 3.1 バリューチェーン全体像

**AIチップ → センサー → モーター → 減速機 → ベアリング → バッテリー → ソフトウェア → ロボット本体**

## 5. 投資の受益順序

Physical AIが本格的な成長局面に入った場合、以下の順序で恩恵が拡大する見込み：

| 順序 | セクター | 主要銘柄（日株） | 理由 |
|------|---------|----------------|------|
| **1次** | AIチップ（GPU・HBM・先端パッケージ） | 4062（イビデン）、6857（アドバンテスト） | 半導体需要が最初に拡大 |
| **2次** | 半導体設備・材料 | 8035（東京エレクトロン）、3110（日東紡績） | 設備投資が続く |
| **3次** | ロボットコア部品（モーター・減速機・ベアリング） | 6324（ハーモニック）、6594（NIDEC）、6471（NSK）、6472（NTN）、6481（THK） | 部品需要が本格化 |
| **4次** | ロボット本体・FAシステム | 6954（ファナック）、6506（安田電機）、6501（日立）、6273（SMC） | システム需要が拡大 |
| **5次** | 下流応用（製造・物流・医療・サービス） | 6383（ダイフク） | 実装が進む |

## 6. 投資リスク

| リスク要因 | 内容 |
|-----------|------|
| **産業化初期リスク** | 2026年は「分水嶺」とされるが、**未だ安定した収益モデルは確立されていない** |
| **技術不確実性** | 世界モデル・シミュレーション技術は**急速な進化過程**にあり、投資対効果は不透明 |
| **量産遅延リスク** | 特斯拉Optimusなど主要ロボットの**量産スケジュール遅延の可能性** |
| **バリュエーションリスク** | 一部銘柄は**短期間で大幅上昇**しており、過熱感あり |
| **政策実行リスク（日本）** | 10.5兆円投資は**2040年度までの長期計画**。短期的な業績寄与は限定的 |
| **地政学リスク** | 米中対立がサプライチェーンや技術移転に影響を与える可能性 |
